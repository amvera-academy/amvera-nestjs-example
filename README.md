# NestJS на Amvera

Простой пример деплоя NestJS в [Amvera](https://amvera.ru).

Это тестовое приложение показывает работу controller, service, DTO-валидации, статических файлов и постоянного хранилища Amvera.

## Демо-приложение

Приложение имеет веб-интерфейс, на котором вы сразу можете выполнить доступные тестовые запросы.

- `GET /api/health`
- `GET /api/items`
- `POST /api/items`
- `DELETE /api/items/{id}`

## Как правильно сохранять файлы

Изменяемые файлы (например, файлы БД) необходимо сохранять в `/data`. В противном случае при пересборке или перезапуске проекта новые данные могут стереться до состояния сборки.

## Статические файлы

Статика находится в `public` и подключается в `main.ts`:

```typescript
app.useStaticAssets("public");
```

## Сборка TypeScript

Во время сборки, помимо стандартного `npm i`, выполняется `npm run build`, так как мы задали его как значение параметра additionalCommands, после чего уже запускается `node dist/main.js`. 

DTO проверяется глобальным `ValidationPipe`, поэтому некорректный JSON не доходит до service.

## Локальный запуск

```bash
npm install
npm run build
npm start
```

Откройте localhost:5000.

## Деплой в Amvera

Для деплоя конкретно этого приложения вам понадобится:

1. Создать аккаунт в [Amvera](https://cloud.amvera.ru);
2. Создать обычное приложение в любом регионе;
3. Загрузить в него код репозитория;
4. Во вкладке "Конфигурация" нажать кнопку "Собрать".

Когда приложение будет готово к работе и статус сменится на "Запущено", во вкладке "Домены" можно будет создать бесплатное доменное имя от Амвера.

Отдельный пример фоновой задачи и worker описан в общей [инструкции по BullMQ](https://github.com/amvera-academy/amvera-nodejs-example/blob/main/BULLMQ.md).
